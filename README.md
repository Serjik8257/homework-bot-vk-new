# homework_bot-vk

Бот проверяет статусы домашних работ в Яндекс Практикуме и отправляет уведомления в личные сообщения ВКонтакте.

## Настройка

1. Установите Python.
2. Создайте виртуальное окружение и установите зависимости:

   ```bash
   python -m venv .venv
   source .venv/Scripts/activate
   python -m pip install -r requirements.txt
   ```

3. Создайте в корне проекта файл `.env` и укажите в нём переменные окружения:

   ```env
   PRACTICUM_TOKEN=токен_Яндекс_Практикума
   VK_TOKEN=токен_сообщества_VK
   VK_USER_ID=числовой_ID_пользователя
   ```

   Не публикуйте значения токенов. Файл `.env` добавлен в `.gitignore`.

## Запуск

Из корня проекта запустите:

```bash
python homework.py
```

Бот запрашивает статусы домашних работ с интервалом 10 минут. События и ошибки записываются в лог.

## Тесты

Запустите автоматические тесты командой:

```bash
python -m pytest
```
